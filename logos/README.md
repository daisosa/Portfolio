# Logos de marcas

Colocá acá el logo en PNG de cada marca con estos nombres exactos (el HTML ya los referencia):

- `hongos-porto.png`
- `cafe-martinez.png`
- `brahma.png`
- `roche.png`
- `oregon-hotel.png`
- `tun.png`

Recomendaciones:
- PNG con fondo transparente.
- Altura real de al menos 120px (se muestra a ~32px, pero conviene subir la imagen más grande para pantallas retina).
- Mientras un archivo no exista, la página muestra automáticamente el nombre de la marca en su lugar — no hay que tocar nada más.
