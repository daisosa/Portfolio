# Logos de marcas

Reemplazá estos placeholders por los logos reales, **con estos mismos nombres de archivo** (podés cambiar la extensión a `.png` o `.jpg`; si lo hacés, avisá para actualizar el `src` en `index.html`):

- `hongos-porto.svg`
- `cafe-martinez.svg`
- `brahma.svg`
- `roche.svg`
- `oregon-hotel.svg`
- `tun.svg`

No hace falta recortarlos al mismo tamaño: el sitio los encuadra automáticamente (`object-fit: contain`) dentro de una caja de 140×44px, sin distorsionar ni cortar el logo.
